# 營運成本估算（評審問「價格合理」「量產難易」用）

以一個鄉鎮 **200 位長者、20 位志工、2 位管理員** 估算。數字依程式實際發送的訊息推得，價格來源在最後。

## 最大的變動成本：LINE 主動推播

LINE 只對「主動推播」計則數；使用者按按鈕、傳訊息後的**回覆不算錢**。本平台大部分互動（按我很好、查詢物資、急救問答、選單）都是回覆。

| 推播 | 誰收到 | 每月則數（200 位長者） |
|---|---|---|
| 每天 08:00 打卡卡片（計畫書核心功能） | 綁定 LINE 的長者 | 200 × 30 ＝ **6,000** |
| 1 小時／3 小時未回應提醒 | 家屬（假設每天 5% 長者未回應） | 約 300 |
| 求救、升級、受理通知 | 管理員、附近志工（假設每月 10 件，每件約 8 則） | 約 80 |
| 日常合計 | | **約 6,400 則** |
| 一次災害（緊急模式） | 點名卡 200 ＋ 其他人廣播 22 ＋ 30／90 分鐘自動再問（約 100＋40）＋ 管理員進度 4 | 約 **370 則／次** |

## 每月費用

| 項目 | 費用 |
|---|---|
| LINE 官方帳號 高用量方案（含 6,000 則；2026/11/1 起） | NT$1,400 |
| 超出的約 400 則 × NT$0.2 | NT$80 |
| 雲端主機與資料庫（Railway） | 約 NT$300 |
| AI 問答（Gemini；有每人每分鐘 5 題限流，額度用完自動改用知識庫原文） | 約 NT$0–100 |
| **合計** | **約 NT$1,800／月，每位長者約 NT$9／月** |

對照：新竹縣「獨居老人在宅緊急救援通報服務」一般戶自付 NT$450／月、為總費用 30%，等於每戶每月約 NT$1,500。本平台不取代硬體救援按鈕，而是用長者已經在用的 LINE，把同一筆預算能照顧的人數放大；需要 24 小時硬體偵測的高風險個案，仍建議搭配救援系統。

## 導入一個新社區要多少人力

| 步驟 | 時間 |
|---|---|
| 開 LINE 官方帳號、部署（照 `docs/FINALS_SETUP.md`） | 半天 |
| 匯入長者名冊、畫分區、設定管理員 | 半天 |
| 志工說明會、長者加好友 | 1–2 次社區活動 |
| 避難所與 AED | 不用建：已內建內政部 5,928 處收容所與衛福部 15,937 台 AED |

軟體複製成本接近零：新社區是設定，不是開發。

## 省錢空間（之後）

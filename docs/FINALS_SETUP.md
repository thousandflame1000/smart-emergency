# 決賽前設定清單

照順序做，全部大約 10 分鐘，**不用打指令、不用記密碼**。每一步做完都可以到後台「系統狀態」確認：目標是**沒有紅色「需處理」**。

正式站：https://smart-emergency-production-d744.up.railway.app

---

## 第 1 步：把自己的 LINE 帳號設成管理員（2 分鐘）

沒有管理員時，有人按「需要幫忙」不會通知任何管理員；沒有照護聯絡人的長者求救會完全沒人知道。

1. 手機加官方帳號 **@571hpppb** 好友，隨便傳一句話（系統會自動幫你註冊）。
2. 電腦開正式站 → 左側「人員管理」，搜尋你的 LINE 名字 → 按「編輯」。
3. 角色**勾「管理員」**，同時**保留「長者」**（單帳號示範時還要用同一支手機回報平安、提出需求）。要示範志工接單就也勾「志工」。
4. 按「儲存」。

確認：「人員管理」篩選「管理員」看得到你；「系統狀態」的「綁定 LINE 的管理員」變綠燈。

## 第 2 步：重裝 LINE 選單（1 分鐘）

> 先確認 LINE Developers 裡「鄰里守望 App」這個 LINE Login channel 已經從 **Developing 改成 Published**，不然只有你自己打得開 App。


後台左側「系統狀態」→「LINE 圖文選單」那一列 → 按 **「重裝 LINE 選單」** → 確認。

約 10 秒完成。手機 LINE 關掉聊天室再打開：你會看到管理員的「決策中心」選單，右下角是「查詢物資」。居民選單的「申請需求」「查看進度」「查詢物資」會直接打開 LINE 裡的全螢幕 App；「緊急求助」「回報平安」一按就完成。

> 要先做第 1 步：重裝時會把所有管理員一起換成管理員選單。

## 第 3 步：在 Railway 開 AI（2 分鐘）

Railway 網站 → 專案 → 服務 → **Variables** 分頁，新增：

| 變數 | 值 | 作用 |
|---|---|---|
| `EXTERNAL_AI_ENABLED` | `true` | LINE 問答改由 Gemini 產生完整回答 |

存檔後 Railway 重新部署一次（約 3–5 分鐘）。

後台預設開放，不用登入。要上鎖時再加 `ADMIN_LINE_LOGIN=true`：筆電打開正式站會出現 QR Code，用手機 LINE 掃描、按送出就登入，12 小時有效。

> `GEMINI_API_KEY` 必須已經設好。「系統狀態」的「AI 問答」還是黃燈，就是這個沒設。

## 第 4 步：打開「系統狀態」總檢查（1 分鐘）

應該是：

- 紅色「需處理」：**0 項**
- 黃色「注意」可以接受的只有「照護聯絡人：N 位長者沒有聯絡人」（示範資料本來就這樣）

有紅燈就照那一列下面的紅字提示修。

## 上台前演練（10 分鐘，至少走一次）

用同一支手機（帳號要同時勾長者、志工、管理員），依決賽 5 分鐘流程。

**開場前**：
- 後台「事件處置工作區」→ 狀態列「緊急求救」→ 把之前測試留下的求救逐筆按「確認已處理」清掉，現場響的才會是新的那一筆。
- 在後台畫面隨便點一下：瀏覽器規定網頁被點過才能出聲，否則新求救只有紅條沒有鈴聲。
- 第一次按紅條的「查看」或「知道了」時，瀏覽器會問要不要顯示通知，按「允許」：之後後台在背景時，新求救也會跳桌面通知。
- 要示範志工接單：在 LINE 傳「登記物資」登記飲用水（例如 10 箱），派遣時才會有候選。

1. **居民回報平安**：選單「首頁」→「我很好」→ 回覆「收到」。後台「總覽」今日平安 +1。
2. **查詢物資**：選單「查詢物資」→ 用手機定位（在華山就用華山）→ 列出最近的收容所，標「內政部公告」，每張有導航。全國 5,928 處都查得到。
3. **提出需求**：選單「服務」→「申請物資」→ 勾飲用水送出。
4. **管理員調度**：後台「事件處置工作區」→ 看到這筆需求 → 按「自動派遣」或點需求「建立待核准建議」→「核准並發 LINE 任務卡」。
5. **志工接單**：手機收到任務卡 →「確認接單」→「已送達」。
6. **一鍵求救**（重點）：手機按「需要幫忙」→ 確認 → **後台 30 秒內響鈴、頂端紅條**，按「查看」直接跳到這筆：地圖上紅色 SOS 在跳動、面板有撥號按鈕、脆弱度與最近打卡。
   → 手機（管理員卡片）按「🙋 我來處理」→ 收到處理人卡片（電話、導航、處理完成）→ 後台變「處理中：你的名字」。
   → 按「✅ 處理完成」→ 結案，求助的人收到通知。任務紀錄看得到受理、結案的時間與人。
   （附近 2 公里內有其他志工時，他們也會收到「附近有人需要幫忙」，第一個按「我過去」的人負責。）
7. **AI 問答**：LINE 直接傳「有人中風怎麼辦？」→ 收到條列步驟與來源。
8. **緊急模式＋災時點名**（最後再示範）：左下「日常模式」切成緊急模式 → 手機收到「請回報是否平安」→ 按「我平安」→ 後台工作區「點名」分頁：平安 +1，還沒回的人依脆弱度排在前面，可以直接撥電話或「標記平安」。志工帳號傳「附近點名」會列出附近還沒回的長者，按「確認平安」後看板同步更新。**注意：切換會廣播給所有 LINE 使用者**，演練完記得切回日常模式。
9. **操作紀錄**：後台「操作紀錄」看到剛才的派遣、核准與模式切換，有時間與操作者。

## 出狀況時

| 狀況 | 先看哪裡 |
|---|---|
| LINE 沒回應 | 「系統狀態」→「LINE 官方帳號」是否綠燈 |
| AI 只回知識庫原文 | 「系統狀態」→「AI 問答」；額度用完時會自動改用原文摘錄，功能不中斷 |
| 新求救沒有響鈴 | 先在後台畫面點一下（瀏覽器規定）；紅條與地圖上的 SOS 不受影響 |
| 查詢物資沒有結果 | 帳號還沒有位置：在 App「物資」按「用我現在的位置」，或 LINE「＋」→ 位置資訊 |
| 後台打不開、要求登入 | 用手機 LINE 掃登入頁的 QR Code、按送出；QR Code 3 分鐘內有效，過期按「產生新的 QR Code」 |
| 不確定正式站是不是最新版 | 開 `/health`，`commit` 應該和 GitHub 最新一筆相同 |

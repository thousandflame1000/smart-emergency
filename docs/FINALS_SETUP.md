# 決賽前設定清單

照順序做，全部大約 10 分鐘，**不用打指令、不用記密碼**。每一步做完都可以到後台「系統狀態」確認：目標是**沒有紅色「需處理」**。

正式站：https://smart-emergency-production-d744.up.railway.app

---

## 第 1 步：把自己的 LINE 帳號設成管理員（2 分鐘）

沒有管理員時，有人按「需要幫忙」不會通知任何管理員；沒有照護聯絡人的長者求救會完全沒人知道。

1. 手機加官方帳號 **@571hpppb** 好友，隨便傳一句話（系統會自動幫你註冊）。
2. 電腦開正式站 → 左側「長者管理」，搜尋你的 LINE 名字 → 點進去「編輯」。
3. 角色**勾「管理員」**，同時**保留「長者」**（單帳號示範時還要用同一支手機回報平安、提出需求）。要示範志工接單就也勾「志工」。
4. 按「儲存」。

確認：左側「志工 / 家屬」→ 篩選「管理員」看得到你；「系統狀態」的「綁定 LINE 的管理員」變綠燈。

## 第 2 步：重裝 LINE 選單（1 分鐘）

後台左側「系統狀態」→「LINE 圖文選單」那一列顯示「舊版」→ 按 **「重裝 LINE 選單」** → 確認。

約 10 秒完成。手機 LINE 關掉聊天室再打開：你會看到管理員的「決策中心」選單，右下角是「查詢物資」。

> 要先做第 1 步：重裝時會把所有管理員一起換成管理員選單。

## 第 3 步：在 Railway 開兩個開關（2 分鐘）

Railway 網站 → 專案 → 服務 → **Variables** 分頁，新增：

| 變數 | 值 | 作用 |
|---|---|---|
| `ADMIN_LINE_LOGIN` | `true` | 後台改成要登入才能開，評審與觀眾不能用手機亂改資料 |
| `EXTERNAL_AI_ENABLED` | `true` | LINE 問答改由 Gemini 產生完整回答 |

兩個一起存，Railway 重新部署一次（約 3–5 分鐘）。

**之後怎麼進後台**：筆電打開正式站，會出現「登入後台」QR Code → **用手機 LINE 掃描、按送出** → 筆電自動登入，12 小時內有效，不用密碼。
（手機上要開後台，就在 LINE 選單按「開啟後台」點連結。）

> `GEMINI_API_KEY` 必須已經設好。「系統狀態」的「AI 問答」還是黃燈，就是這個沒設。

## 第 4 步：打開「系統狀態」總檢查（1 分鐘）

應該是：

- 紅色「需處理」：**0 項**
- 黃色「注意」可以接受的只有「照護聯絡人：N 位長者沒有聯絡人」（示範資料本來就這樣）

有紅燈就照那一列下面的紅字提示修。

## 上台前演練（10 分鐘，至少走一次）

用同一支手機，依決賽 5 分鐘流程。

**事前準備（只做一次）**：要示範志工接單，這支手機的帳號要勾「志工」，並在 LINE 傳「登記物資」登記飲用水（例如 10 箱，位置同樣拖到玉里），派遣時才會有候選。


1. **居民回報平安**：選單「回報平安」→ 回覆「收到」。後台「總覽」今日平安 +1。
2. **查詢物資**：選單「查詢物資」→ 沒位置時按「分享我的位置」，**在 LINE 地圖上拖到花蓮玉里再送出**（不要用華山會場的定位）→ 按「查詢附近物資」→ 看到玉里衛生所、消防分隊、玉里國小的卡片，每張有「導航」按鈕。
3. **提出需求**：選單「申請需求」→ 勾飲用水送出。
4. **管理員調度**：後台「事件處置工作區」→ 看到這筆需求 → 按「自動派遣」或點需求「建立待核准建議」→「核准並發 LINE 任務卡」。
5. **志工接單**（第 1 步有勾志工才能示範）：手機收到任務卡 →「確認接單」→「已送達」。
6. **AI 問答**：LINE 直接傳「有人中風怎麼辦？」→ 收到條列步驟與來源。
7. **緊急模式**（最後再示範）：後台左下「日常模式」切成緊急模式 → 畫面頂端紅色橫幅、總覽地圖開啟應變據點圖層。**注意：切換會廣播給所有 LINE 使用者**，演練完記得切回日常模式。
8. **操作紀錄**：後台「操作紀錄」看到剛才的派遣、核准與模式切換，有時間與操作者。

「一鍵求助」只示範到跳出確認卡為止，按「沒事」取消，不要在正式帳號送出測試求救。

## 出狀況時

| 狀況 | 先看哪裡 |
|---|---|
| LINE 沒回應 | 「系統狀態」→「LINE 官方帳號」是否綠燈 |
| AI 只回知識庫原文 | 「系統狀態」→「AI 問答」；額度用完時會自動改用原文摘錄，功能不中斷 |
| 查詢物資列出很遠的地方 | 重新分享位置，在 LINE 地圖上拖到玉里 |
| 後台打不開、要求登入 | 用手機 LINE 掃登入頁的 QR Code、按送出；QR Code 3 分鐘內有效，過期按「產生新的 QR Code」 |
| 不確定正式站是不是最新版 | 開 `/health`，`commit` 應該和 GitHub 最新一筆相同 |
